# Figma Make prompt — Lifeline recovery circle

**Limit target:** < 5000 characters  
**Source brief:** design-brief-lifeline.md

```
Design a responsive web UI for Lifeline, a privacy-first financial recovery circle.

Brand: Lifeline. Tagline near brand: “Private support. Collective decisions.”
Tone: calm, dignified, clear. Not neon crypto. Not purple-gradient SaaS. Not cream/serif terracotta cliché.

Typography: Manrope for UI, Georgia sparingly for short emphasis.
Atmosphere: soft daylight blue-gray gradient background, subtle depth, no flat white slab.
Accent: sober teal for primary buttons. Amber label for “Local demo”. Green label for “Midnight Preprod + Lace”.

First viewport (Overview): one composition — brand Lifeline as hero signal, one headline about private collective priority, one short supporting sentence, one CTA group (“Publicar na Preprod”, “Copiar convite”), dominant full-bleed atmospheric visual of quiet support/restart (not charts, not card collage). No stats strip, no floating badges on the image, no card grid in the hero.

Below fold sections (one job each):
1) Needs — list/interactive rows for local needs (title, category; amounts hideable). Modal to add need.
2) Voting — supporter prioritizes one need; show capped weight; disable after vote.
3) Results — winning commitment + transaction id.
4) Privacy — three columns: Private / Proven / Public.

Chrome: top network strip always visible (Demo vs Preprod). Role switch Beneficiary/Supporter. Protect values toggle.

Components: use cards only for interactive need rows and modals. 44px touch targets. WCAG AA contrast. Mobile and desktop frames.

Motion: short fade on view change; gentle toast on copy invite; subtle success on vote.

Copy language: Portuguese (Brazil). Explicit honesty: demo receipts never look like blockchain txs.
```
