# Lifeline — Private Recovery Circle

**Status:** In Progress (MVP hackathon entregue; discovery pós-MVP aberta)  
**Timeline:** 2026-06 → 2026-08 (estabilização + discovery)  
**Owner:** Product  
**Stakeholders:** Engineering, Design/UX, juízes MLH Midnight DeFi Track

## Initiative Goal

Permitir que um beneficiário e apoiadores de confiança priorizem uma obrigação financeira urgente com votação ponderada verificável na Midnight, sem publicar descrições, valores, credores ou identidades no ledger.
